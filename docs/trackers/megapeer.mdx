Megapeer, slug `megapeer`, содержит около 113 тысяч раздач и работает без авторизации. Сайт отдаёт HTML в кодировке cp1251, JacRed автоматически конвертирует её в UTF-8. Парсер устанавливает `Referer` при обходе категорий. Входит в trio-кластер.

## Конфигурация

```yaml
Megapeer:
  host: http://megapeer.vip
  alias: ""
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
```

## Расписание cron

```crontab
# Парсинг раз в час
8 * * * *  /opt/jacred/Data/run-job.sh megapeer-parse http://127.0.0.1:9117/cron/megapeer/parse 900

# Обновление очереди раз в сутки
20 2 * * *  /opt/jacred/Data/run-job.sh megapeer-UpdateTasksParse http://127.0.0.1:9117/cron/megapeer/UpdateTasksParse 60

# Полный перебор раз в сутки утром
45 4 * * *  /opt/jacred/Data/run-job.sh megapeer-ParseAllTask http://127.0.0.1:9117/cron/megapeer/ParseAllTask 60
```

<Note>
  После рестарта незавершённый цикл продолжает `GET /cron/maintenance/ResumeParseAll` (~45 с после старта и cron `*/15`). Утренний `ParseAllTask` начинает новый круг только когда pending = 0.
</Note>

## Особенности

- **Кодировка cp1251**: JacRed конвертирует названия и описания в UTF-8 автоматически.
- **Магниты по запросу**: magnet извлекается со страницы каждой раздачи.
- **Referer**: устанавливается автоматически при обходе категорий.
