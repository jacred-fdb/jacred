TorrentBy, slug `torrentby`, содержит около 58 тысяч раздач. Белорусский трекер, работает без авторизации. Входит в trio-кластер. При региональной блокировке основного домена укажите Cloudflare Worker в поле `alias`.

## Конфигурация

```yaml
TorrentBy:
  host: https://torrent.by
  alias: ""            # например: https://torrentby.workers.dev
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
```

<Tip>
  Если основной домен `torrent.by` заблокирован, разверните Cloudflare Worker с проксированием запросов и укажите его URL в `alias`. FDB-ссылки останутся на `host`, HTTP-запросы пойдут через alias.
</Tip>

## Расписание cron

```crontab
# Парсинг каждые 15 минут
7,22,37,52 * * * *  /opt/jacred/Data/run-job.sh torrentby-parse http://127.0.0.1:9117/cron/torrentby/parse 900

# Обновление очереди
25 2 * * *  /opt/jacred/Data/run-job.sh torrentby-UpdateTasksParse http://127.0.0.1:9117/cron/torrentby/UpdateTasksParse 60

# Полный перебор каждые 6 часов (~197 страниц, минуты)
50 5,11,17,23 * * *  /opt/jacred/Data/run-job.sh torrentby-ParseAllTask http://127.0.0.1:9117/cron/torrentby/ParseAllTask 60
```

<Note>
  После рестарта незавершённый цикл продолжает `GET /cron/maintenance/ResumeParseAll` (~45 с после старта и cron `*/15`). Cron `ParseAllTask` начинает новый круг только когда pending = 0. Полная матрица — [Cron](/deployment/cron).
</Note>

`ParseAllTask` обходит только страницы из `Data/temp/torrentby_taskParse.json`. Карту собирает `UpdateTasksParse`: читает живой пейджер `circle_page` (в том числе через ссылки `...`) и **удаляет** слоты за последней реальной страницей. Пустой ответ карту не обнуляет. После смены пагинации один раз вызовите:

```bash
curl "http://127.0.0.1:9117/cron/torrentby/UpdateTasksParse"
```

Новые страницы дописываются; `page: 0` остаётся. Следующий `ParseAllTask` обработает ещё не пройденные страницы текущего цикла.

## Диагностика

```bash
curl "http://localhost:9117/cron/torrentby/parse"
tail -f /opt/jacred/Data/log/torrentby.log
```
