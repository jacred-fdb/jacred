Toloka, slug `toloka`, содержит около 58 тысяч раздач. Украинский трекер, требует авторизации через cookie или логин/пароль. Входит в trio-кластер.

## Конфигурация

<CodeGroup>

```yaml Cookie (предпочтительно)
Toloka:
  host: https://toloka.to
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
  cookie: "toloka_sid=SESSION; toloka_uid=USER_ID"
```

```yaml Логин/пароль
Toloka:
  host: https://toloka.to
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
  login:
    u: "mylogin"
    p: "mypassword"
```

</CodeGroup>

### Как получить cookie

1. Войдите в аккаунт на toloka.to в браузере.
2. DevTools (F12) → Application → Cookies → toloka.to.
3. Скопируйте значения `toloka_sid` и `toloka_uid` в поле `cookie`.

## Расписание cron

```crontab
14,54 * * * *  /opt/jacred/Data/run-job.sh toloka-parse http://127.0.0.1:9117/cron/toloka/parse 900
30 2 * * *  /opt/jacred/Data/run-job.sh toloka-UpdateTasksParse http://127.0.0.1:9117/cron/toloka/UpdateTasksParse 60
55 4 * * *  /opt/jacred/Data/run-job.sh toloka-ParseAllTask http://127.0.0.1:9117/cron/toloka/ParseAllTask 60
```

<Note>
  После рестарта незавершённый цикл продолжает `GET /cron/maintenance/ResumeParseAll` (~45 с после старта и cron `*/15`). Утренний `ParseAllTask` начинает новый круг только когда pending = 0.
</Note>

## Диагностика
