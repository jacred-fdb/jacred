JacRed 3.9.3 включает 25 встроенных slug трекеров. Если `synctrackers` не задан, API каталога возвращает встроенный список без элементов из `disable_trackers`. Если `synctrackers` задан, каталог строится только из него. Ниже — сводка по кластерам синхронизации.

## Trio-кластер

Полный цикл задач: `parse` (частый) + `UpdateTasksParse` (раз в сутки) + `ParseAllTask` (раз в сутки утром; после рестарта продолжает `ResumeParseAll`).

| Slug | Хост | Авторизация | Объём | Особенности |
| --- | --- | --- | --- | --- |
| [`rutracker`](/trackers/rutracker) | rutracker.org | FlareSolverr | ~1.5M | Cloudflare |
| [`kinozal`](/trackers/kinozal) | kinozal.guru | cookie или login + FlareSolverr | ~550k | Cloudflare, cp1251 |
| [`rutor`](/trackers/rutor) | rutor.info | нет | ~550k | Магниты в списке |
| [`nnmclub`](/trackers/nnmclub) | nnmclub.to | нет | ~145k | cp1251, .onion |
| [`megapeer`](/trackers/megapeer) | megapeer.vip | нет | ~113k | cp1251 |
| [`toloka`](/trackers/toloka) | toloka.to | cookie или login | ~58k |  |
| [`torrentby`](/trackers/torrentby) | torrent.by | нет | ~58k | Worker alias |

## Кодировки

Большинство трекеров используют UTF-8. Исключения с Windows-1251 (JacRed конвертирует автоматически):

- kinozal, nnmclub, megapeer, rudub, baibako, anistar

## Общие поля конфигурации

Все блоки трекеров поддерживают одинаковый набор ключей:

| Поле | Тип | Описание |
| --- | --- | --- |
| `host` | string | Канонический URL трекера |
| `alias` | string | Зеркало или Worker URL для HTTP-запросов |
| `useproxy` | bool | Направлять запросы через `proxy` или `globalproxy` |
| `reqMinute` | int | Максимум запросов в минуту (по умолчанию 8) |
| `parseDelay` | int | Задержка между страницами, мс (по умолчанию 7000) |
| `log` | bool | Отдельный лог `Data/log/{tracker}.log` |
| `cookie` | string | Статический cookie (предпочтительно, где поддерживается) |
| `login.u` / `login.p` | string | Логин и пароль |

Подробнее: [Настройка трекеров в init.yaml](/configuration/trackers).
