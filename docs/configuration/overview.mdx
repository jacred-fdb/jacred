JacRed хранит всю конфигурацию в одном файле — `init.yaml` (или `init.conf` для JSON-формата). Приложение читает файл из **рабочей директории**. В Docker это `/app/init.yaml`: entrypoint копирует его из постоянного тома `/app/config`. Данные остаются отдельно в `/app/Data`. Конфиг перечитывается автоматически каждые ~10 секунд без перезапуска.

`Data/init.yaml` в репозитории — шаблон, а не runtime-файл.

## Слои значений по умолчанию

| Слой | Файл | Когда действует |
| --- | --- | --- |
| Код | `Configuration/AppOptions.cs` | Ключ отсутствует в runtime-файле |
| Шаблон | `Data/init.yaml` | Новая установка `jacred.sh` и образ Docker копируют этот файл |
| Пример | `Data/example.yaml` | Иллюстрация полного конфига. Не подставляйте его токены в прод |

Ключи, которые расходятся между слоями:

| Параметр | `AppOptions.cs` | `Data/init.yaml` | `Data/example.yaml` |
| --- | --- | --- | --- |
| `opensync` | `true` | `false` | `true` |
| `syncapi` | пусто | пусто | `https://sync.jacred.stream` |
| `syncsport` | `true` | `false` | `true` |
| `syncspidr` | `true` | `false` | `true` |
| `maxreadfile` | `200` | `250` | `250` |
| `timeStatsUpdate` | `90` | `15` | `15` |
| `timeSync` | `60` | `120` | `120` |
| `timeSyncSpidr` | `60` | `360` | `360` |
| `evercache.enable` | `true` | `false` | `false` |
| `flaresolverr.enable` | `true` | `true` | `true` |
| `cffetch.enable` | `true` | `true` | `true` |

Таблица ниже показывает **C# defaults**. Установленный инстанс почти всегда переопределяет их шаблоном `init.yaml`.

## Приоритет файлов

1. `init.yaml` (YAML-формат, предпочтительный)
2. `init.conf` (JSON-формат)

Если оба файла существуют, используется `init.yaml`.

## Веб-редактор

Откройте `http://YOUR_HOST:9117/settings` для редактирования конфигурации через браузер. Веб-редактор требует LAN-доступа или заголовка `X-Dev-Key`.

<Warning>
  В Docker редактор сохраняет рабочий `/app/init.yaml`. Entrypoint не копирует его обратно в `/app/config`. Для постоянного изменения отредактируйте файл в смонтированном томе `/app/config`.
</Warning>

## Глобальные параметры

Значения — инициализаторы `AppOptions`, если ключ не задан в файле.

| Параметр | Тип | По умолчанию (C#) | Описание |
| --- | --- | --- | --- |
| `listenip` | string | `any` | IP для прослушивания |
| `listenport` | int | `9117` | Порт |
| `apikey` | string | пусто | Ключ для поисковых эндпоинтов |
| `devkey` | string | пусто | Ключ для административных эндпоинтов |
| `mergeduplicates` | bool | `true` | Объединять семантические дубли |
| `mergenumduplicates` | bool | `true` | Объединять числовые дубли |
| `openstats` | bool | `true` | Открыть `/stats/*` без ключа |
| `opensync` | bool | `true` | Открыть `/sync/*` для внешних клиентов |
| `web` | bool | `true` | Включить веб-интерфейс |
| `logFdb` | bool | `true` | Логировать изменения FileDB |
| `logFdbRetentionDays` | int | `7` | Хранить логи N дней |
| `logParsers` | bool | `true` | Логировать работу парсеров |
| `maxreadfile` | int | `200` | Макс. записей из одного шарда FileDB |
| `fdbPathLevels` | int | `2` | Уровни вложенности директорий FileDB |
| `timeStatsUpdate` | int | `90` | Интервал обновления stats.json, минуты |
| `timeSync` | int | `60` | Интервал синхронизации, минуты |
| `syncapi` | string | пусто | URL сервера синхронизации |

## Минимальный init.yaml

```yaml
listenip: any
listenport: 9117
apikey: "your-api-key"
devkey: "your-dev-key"
```

## Полная структура конфига

Фрагмент ниже следует шаблону `Data/init.yaml` (не C# defaults): `opensync: false`, `maxreadfile: 250`, `timeStatsUpdate: 15`.

```yaml
listenip: any
listenport: 9117
apikey: ""
devkey: ""

# Объединение дублей
mergeduplicates: true
mergenumduplicates: true

# Доступность эндпоинтов
openstats: true
opensync: false
web: true

# Логирование FileDB
logFdb: true
logFdbRetentionDays: 7
logFdbMaxSizeMb: 0
logFdbMaxFiles: 0
logParsers: true

# FileDB
maxreadfile: 250
fdbPathLevels: 2

# Синхронизация
syncapi: ""
synctrackers: [rutracker, kinozal, rutor]
disable_trackers: []
syncsport: false
syncspidr: false
timeSync: 120
timeSyncSpidr: 360
saveCheckpointEveryNBatches: 5
timeStatsUpdate: 15

# Поиск
search:
  mergeV1: auto
  maxV1Pairs: 4
  v1Sort: sid
  stripTrailingYear: true
  stripSeasonEpisode: true
  skipSeasonEpisodeFilter: false
  skipCatFilter: true

# Torznab
torznab:
  enable: true
  enrichTitles: true

# Alloha TV API (для ID-поиска)
# alloha:
#   enable: true
#   token: ""
#   cacheHours: 24

# FlareSolverr (Rutracker, Kinozal)
flaresolverr:
  enable: true
  url: http://127.0.0.1:8191/v1

# Tracks-модуль
tracks: false
tsuri:
  - http://127.0.0.1:8090

# Блоки трекеров
Rutracker:
  host: https://rutracker.org
```

## Config API

Конфиг можно читать и изменять программно:

```bash
# Прочитать текущий конфиг
curl "http://localhost:9117/api/v1.0/config?format=yaml" \
  -H "X-Dev-Key: YOUR_DEV_KEY"

# Сохранить новый конфиг
curl -X POST "http://localhost:9117/api/v1.0/config" \
  -H "X-Dev-Key: YOUR_DEV_KEY" \
  -H "Content-Type: application/json" \
  -d '{"content": "listenport: 9117\napikey: newkey"}'
```

Подробнее в разделе [Config API](/api-reference/config).
