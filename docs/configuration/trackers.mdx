Каждый трекер JacRed конфигурируется отдельным блоком в `init.yaml`. Имя блока совпадает со slug трекера (с заглавной первой буквой). Правильная настройка хоста и авторизации критична для стабильной работы крон-парсеров.

## Структура блока трекера

```yaml
TrackerName:
  host: "https://tracker.example.com"
  alias: "https://mirror.example.com"
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  log: true
  cookie: "uid=USER_ID; pass=PASS_HASH"
  login:
    u: "username"
    p: "password"
```

<ParamField path="host" type="string" required>
  Базовый URL трекера. Используется парсером для построения всех запросов.
</ParamField>

<ParamField path="alias" type="string">
  Зеркало или Worker URL. JacRed подставляет alias в реальные запросы вместо host.
</ParamField>

<ParamField path="useproxy" type="boolean">
  Направлять запросы к трекеру через прокси из секции `proxy` или `globalproxy`.
</ParamField>

<ParamField path="reqMinute" type="number">
  Максимальное число запросов в минуту. По умолчанию: 8. Уменьшите при получении ошибок 429.
</ParamField>

<ParamField path="parseDelay" type="number">
  Задержка между страницами при парсинге, миллисекунды. По умолчанию: 7000.
</ParamField>

<ParamField path="log" type="boolean">
  Включить отдельное журналирование для этого трекера.
</ParamField>

<ParamField path="cookie" type="string">
  Статическая строка сессионных cookie. Предпочтительный способ авторизации (не требует повторного логина).
</ParamField>

<ParamField path="login.u" type="string">
  Логин для авторизации. Используется, если `cookie` не задан.
</ParamField>

<ParamField path="login.p" type="string">
  Пароль для авторизации.
</ParamField>

## Пример конфигурации Kinozal

<CodeGroup>

```yaml Cookie (предпочтительно)
Kinozal:
  host: https://kinozal.guru
  useproxy: false
  reqMinute: 4
  parseDelay: 10000
  log: true
  cookie: "uid=USER_ID; pass=PASS_HASH"
```

```yaml Логин/пароль
Kinozal:
  host: https://kinozal.guru
  useproxy: false
  reqMinute: 4
  parseDelay: 10000
  log: true
  login:
    u: "mylogin"
    p: "mypassword"
```

</CodeGroup>

<Warning>
  Не сохраняйте реальные логины, пароли и cookie в публичных репозиториях. Используйте Docker secrets или переменные окружения.
</Warning>

## Пример конфигурации Rutracker

```yaml
Rutracker:
  host: https://rutracker.org
  alias: ""
  useproxy: false
  reqMinute: 8
  parseDelay: 7000
  topicFetchAttempts: 5
  log: true
```

Rutracker требует отдельной настройки FlareSolverr. Подробнее на странице [FlareSolverr](/configuration/flaresolverr).
